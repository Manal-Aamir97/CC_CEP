Scoring conventions:

- A missing, empty or unchosen value counts as failing the rule that checks it.
- A source 'allows' an address when the address is inside the source CIDR (203.0.113.25 is inside 0.0.0.0/0 and inside 203.0.113.0/24).
- World-open sources are 0.0.0.0/0 and ::/0.
- One mistake is counted once: when a high rule and a medium rule look at the same field, a world-open source is scored only by the high rule (see each rule's 'precedence').
- Task success = no failed high-severity rule (build plan, Metrics).
